# Velvet Ledger (prototype)

Source-only design prototype for a creator-owned adult platform concept. Static HTML/CSS/JS, no dependencies.

**This is not** operational adult video hosting, age verification, identity verification, payments, or legal compliance. It contains no adult content (placeholders only), collects no data (the submission form has no backend and form-action is blocked by CSP), and is not deployed anywhere.

Sections: home, creators, explore (search/filter), about, safety/age-gate concept, creator submission with ownership/consent attestation, contact/report/takedown, privacy and terms placeholders.

Run: `npm test`, `npm run build` (outputs dist/ locally), open src/index.html.

A real launch would need accredited age and ID verification, counsel, consent records, payment compliance, and CSAM/NCII reporting processes.
